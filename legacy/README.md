# Legacy HTML prototype (pre-React)

The original vanilla HTML/CSS/JS Website Builder prototype, preserved verbatim.
It proved the UX; the React app at the repo root is the production foundation.

Run it:  `node legacy/server.js`  →  http://localhost:4173/builder.html

- `builder.html` — the production-UX builder prototype (Passes 1–4)
- `index.html`   — the earlier hi-fi "switch on your site" flow (Step 3)
- `assets/`      — its CSS + JS
- `server.js`    — dependency-free static server

Nothing here is imported by the React app. Kept for reference and recovery.
